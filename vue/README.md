# 🔢 Number Parity Checker

A real-time, reactive Even/Odd number checker built with **Vue 3** and **Tailwind CSS**. 

This project demonstrates precise state management and edge-case handling in Vue 3, specifically focusing on how to correctly evaluate the number `0` in JavaScript.

---

### ✨ Features

- **Real-Time Validation:** Instantly evaluates if the input is Even or Odd as the user types.
- **Zero Edge-Case Handling:** Correctly identifies `0` as an Even number, avoiding the common JavaScript `!0` truthy/falsy trap.
- **Conditional Rendering:** Uses Vue's `v-if` to cleanly hide the result when the input is empty.
- **Minimalist UI:** Features a clean, centered design with smooth focus states and bold typography.

---

### 🛠️ Tech Stack

-  **Vue 3** (Composition API with `<script setup>`)
- 🎨 **Tailwind CSS** (Utility-first styling)
